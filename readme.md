---

## 1. 목표

브라우저에서 동작하는 **우주선(로켓) 발사 시뮬레이션**. 발사 버튼을 누르면 로켓이 실제로 날아가는 것처럼 움직이고, 시간·속력·고도가 실시간으로 표시되며, 단(stage)이 분리되는 모습과 각 단계의 성공/실패가 보여야 한다.

---

## 2. 필수 기능 (요청 사항)

| # | 기능 | 설명 |
|---|------|------|
| 1 | **발사 버튼** | 누르면 카운트다운 → 점화 → 이륙 시퀀스 시작 |
| 2 | **리셋 버튼** | 언제든 누르면 로켓·시간·속력·분리 상태·판정을 모두 초기 상태(발사대)로 되돌림 |
| 3 | **실제로 날아가는 동작** | 이륙 → 상승 → 중력선회(점점 수평으로 기울기) → 궤도 진입까지 연속적인 움직임 |
| 4 | **속력 표시** | 현재 속도(km/s) 실시간 표시, 연료 소모에 따라 가속 |
| 5 | **시간 표시** | 비행 시간 `T+ 00:00` (발사 전에는 `T−` 카운트다운) |
| 6 | **분리되는 모습** | 1단 → 페어링 → 2단 순서로 분리, 분리된 부분은 따로 떨어져 나가는 애니메이션 |
| 7 | **정상 작동 여부** | 각 단계마다 성공/실패 판정 표시, 비행 종료 시 최종 결과(임무 성공/실패) 표시 |

## 3. 참고 사이트를 보고 추가한 항목

### 3-1. naroho_simulator에서 가져온 구성
- **고도(ALTITUDE) 표시** 추가 — 시간·속력과 함께 3대 텔레메트리
- **상태 표시** — `STANDBY / READY · PAD / LIVE` 같은 비행 상태 배지
- **일시정지(PAUSE) / 다시보기(REPLAY)** 버튼
- **수동 분리(MANUAL OVERRIDE)** — 1단·2단·페어링 분리 버튼, 각각 `ATTACHED / SEPARATED` 상태 표시
- **시뮬레이션 배속**(예: 1.0× ~ 4.0×)
- **3D 뷰 조작** — 드래그로 회전, 스크롤로 확대/축소
- **"교육용 개념 모델이며 실제 성능을 재현하지 않는다"는 고지문** 하단에 표시

### 3-2. SPACESTARX에서 가져온 아이디어
- **미션 타임라인** — 이벤트가 시간순으로 진행되고, 지나간 이벤트는 체크 표시 (아래 6장 참고)
- **Max-Q(최대 동압) 구간** — 속도·대기압이 겹쳐 구조에 가장 큰 부하가 걸리는 구간을 표시
- **실패할 수 있는 물리** — 동압 한계, 추진제(연료) 잔량, 분리 타이밍 등을 넘으면 실제로 실패
- **난이도(쉬움/보통/어려움)** — 쉬움은 자동 보조, 어려움은 수동 타이밍 요구
- **자동 방송 카메라** — 여러 시점(발사대, 측면 추적, 로켓 탑재 카메라)을 자동 전환 또는 수동 선택
- **불꽃·증기·분리 파편 효과**, **카운트다운 음성/효과음**(음소거 버튼 포함)
- **다국어(한국어/영어)** 및 **모바일(세로·가로) 대응**
- **임무 요약 화면** — 비행 종료 후 최고 속도, 최고 고도, 분리 성공 횟수, 총 비행 시간

## 5. 비행 상태 머신

```
STANDBY(대기) ─[발사]→ COUNTDOWN ─→ IGNITION ─→ ASCENT(상승)
   ↑                                              │
   │                         ┌────────────────────┼───────────────┐
   │                         ▼                    ▼               ▼
   │                  STAGE_SEPARATION       FAILURE(실패)    ORBIT(궤도 진입)
   │                         │                                    │
   └──────────────[리셋: 어느 상태에서나 즉시]──────────────────────┘
```

- **리셋**은 모든 상태에서 동작해야 하며, 타이머·애니메이션·효과음을 모두 정리하고 초기값으로 복원한다.
- 일시정지 중에도 리셋은 가능해야 한다.

## 6. 미션 타임라인 (예시 값 — 조정 가능)

> 아래 수치는 **교육용 예시**입니다. 실제 발사체의 성능을 재현하지 않으며, 코드에서는 설정 파일(`config`)로 분리해 쉽게 바꿀 수 있게 합니다.

| 시각 | 이벤트 | 속력(예시) | 고도(예시) | 판정 기준 |
|------|--------|-----------|-----------|-----------|
| T−00:10 | 카운트다운 시작 | 0 | 0 | — |
| T+00:00 | 점화·이륙 | 0 | 0 | 엔진 추력 ≥ 중량 |
| T+00:60 | Max-Q 통과 | 0.5 km/s | 12 km | 동압 한계 이내 |
| T+02:00 | **1단 분리** | 2.5 km/s | 60 km | 연료 소진 후 정해진 시간 창 안에 분리 |
| T+03:00 | **페어링 분리** | 3.0 km/s | 110 km | 대기 밀도가 충분히 낮아진 뒤 분리 |
| T+08:00 | **2단 분리** | 7.6 km/s | 300 km | 궤도 속도 도달 후 분리 |
| T+08:30 | 궤도 진입 | 7.6 km/s | 300 km | 속도·고도가 목표 범위 안 |

### 단계별 판정
- ✅ **정상(NOMINAL)** — 기준 만족
- ⚠️ **주의(WARNING)** — 기준에 근접 (타이밍 약간 어긋남 등)
- ❌ **실패(FAILURE)** — 기준 초과 (너무 이른/늦은 분리, 연료 고갈, 동압 초과). 실패하면 비행 중단 후 실패 원인 표시

## 7. 분리 연출 요구사항

- 분리 순간 **섬광/가스 분출 효과**와 짧은 흔들림
- 분리된 단은 **원래 속도를 유지한 채 서서히 뒤처지고 회전하며 낙하**
- 본체는 **질량이 줄어든 만큼 가속이 커짐**(분리 후 가속 변화가 눈에 보이게)
- 분리 시 해당 단의 상태 배지가 `ATTACHED → SEPARATED`로 바뀌고 타임라인에 체크
- 자동 분리와 **수동 분리(MANUAL OVERRIDE)** 모두 지원 (수동 시 타이밍이 틀리면 실패 판정)

## 8. 데이터 모델 (제안)

```js
const state = {
  phase: "STANDBY",        // STANDBY | COUNTDOWN | ASCENT | SEPARATION | ORBIT | FAILURE
  t: 0,                    // 비행 시간(초), 카운트다운은 음수
  speed: 0,                // km/s
  altitude: 0,             // km
  fuel: 100,               // %
  stages: {
    first:   { attached: true, status: "ATTACHED" },
    fairing: { attached: true, status: "ATTACHED" },
    second:  { attached: true, status: "ATTACHED" },
  },
  events: [],              // { name, time, result: "OK" | "WARN" | "FAIL" }
  result: null,            // "SUCCESS" | "FAILURE"
  timeScale: 1.0,
  paused: false,
};
```

- 프레임 루프(`requestAnimationFrame`)에서 `dt × timeScale`만큼 상태를 갱신
- **리셋 = `state`를 초기값 객체로 교체 + 3D 오브젝트 위치/가시성 복원**

## 9. 완료 기준 (체크리스트)

**필수**
- [ ] 발사 버튼을 누르면 카운트다운 후 로켓이 이륙한다
- [ ] 리셋 버튼이 비행 중·일시정지 중·종료 후 어디서든 초기 상태로 되돌린다
- [ ] 로켓이 시간에 따라 연속적으로 상승하고 점점 수평으로 기운다
- [ ] 비행 시간(T+), 속력, 고도가 실시간으로 갱신된다
- [ ] 1단·페어링·2단이 순서대로 분리되고, 분리된 부분이 따로 떨어져 나가는 모습이 보인다
- [ ] 각 단계의 정상/주의/실패 판정과 최종 결과가 화면에 표시된다
- [ ] 리셋 후 다시 발사해도 똑같이 동작한다 (잔여 상태 없음)

**추가 (권장)**

- [ ] 연료 게이지, Max-Q 표시
- [ ] 미션 타임라인 체크 표시
- [ ] 비행 종료 요약 화면
- [ ] 난이도 선택, 카메라 전환
- [ ] 효과음·음소거, 한국어/영어 전환
- [ ] 모바일 화면 대응
- [ ] "교육용 모델" 고지문

## 10. 구현 순서 (제안)

1. **뼈대** — 화면 레이아웃, 발사·리셋 버튼, 상태 객체
2. **비행 루프** — 시간·속력·고도 계산과 표시
3. **로켓 움직임** — 이륙, 상승, 기울기 변화
4. **단 분리** — 이벤트 타이밍, 분리 애니메이션, 상태 배지
5. **판정 로직** — 단계별 성공/실패, 결과 화면
6. **완성도** — 일시정지/배속, 수동 분리, 효과·사운드, 모바일 대응
